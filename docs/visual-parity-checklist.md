# Visual Parity Checklist

- [ ] Screen hierarchy matches the reference
- [ ] Section order and information priority match
- [ ] Horizontal margins and vertical spacing are consistent
- [ ] Font family, size, weight, and line height are appropriate
- [ ] Button and text-field dimensions are correct
- [ ] Card radius, border, and icon alignment are correct
- [ ] Gauge has a bounded parent
- [ ] Chart has a bounded parent
- [ ] Canvas does not escape parent bounds
- [ ] No overlap with adjacent text
- [ ] No clipping
- [ ] Score and labels are aligned correctly
- [ ] Status/navigation-bar insets are correct
- [ ] Gesture area does not cover controls
- [ ] Larger font scale remains usable
- [ ] Touch targets and screen-reader semantics are appropriate
- [ ] Localized text remains usable
- [ ] RTL behavior is reviewed when supported
- [ ] Android screenshot captured
- [ ] Screenshot compared with iOS reference
- [ ] Compact and standard widths reviewed
- [ ] Intentional platform differences documented
