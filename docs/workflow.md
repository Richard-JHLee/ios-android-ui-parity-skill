# Workflow

1. Identify the exact screen or feature.
2. Inspect the reference screenshot, SwiftUI source, ViewModel, models, API service, assets, and design tokens.
3. Record hierarchy, spacing, typography, colors, sizes, states, accessibility, and localization behavior.
4. Map to Android-native architecture.
5. Implement only the required scope.
6. Validate loading, success, empty, error, navigation, and API mapping.
7. Capture an Android screenshot and compare offsets, margins, spacing, typography, icons, charts, gauges, Canvas bounds, and insets.
8. Validate compact/standard widths, larger font scale, and RTL when supported.
9. Document intentional platform differences.
